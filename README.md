# ForgeAIMCP

MCP для Minecraft 1.7.10: предметы, рецепты NEI, применения и ордикты.
Нужны Forge, Forgelin, NotEnoughItems и его зависимости.

## Быстрый старт

1. Положите JAR мода в `mods/` и запустите игру.
2. Войдите в мир и выполните `/forgemcp start`.
3. Выполните `/forgemcp config` и нажмите на ссылку в чате.
4. Добавьте запись из готового `mcp.json` в настройки вашего MCP-клиента.
   Для настроек в TOML используйте блок из `codex.toml`.

Все файлы распаковываются автоматически в папку `forgemcp/` рядом с `mods/`.
Пути к Java, мосту и порт уже заполнены. Python и отдельная установка Java не нужны.
Подключение в MCP-клиенте настраивается один раз.

## Команды

- `/forgemcp start` — запустить MCP.
- `/forgemcp stop` — остановить MCP.
- `/forgemcp status` — проверить состояние.
- `/forgemcp config` — открыть папку с готовыми настройками подключения.
- `/forgemcp ui` — запустить и открыть локальный редактор рецептов.

Команды клиентские, работают в одиночной игре и на сервере без прав администратора.
MCP доступен только с этого компьютера. При выходе из мира он останавливается.

## Настройки

Файл `config/forgeaimcp.cfg` создаётся автоматически:

```text
mcp {
    B:autoStart=false
    I:port=25576
    I:webPort=25577
}
```

Автостарт по умолчанию выключен. `autoStart=true` включает запуск при инициализации клиента.
После выхода и повторного входа в мир нужна команда запуска.
После изменения настроек перезапустите игру: файлы подключения обновятся автоматически.
Мод обновляет свои файлы в `forgemcp/`; пользовательские настройки подключения меняйте в MCP-клиенте.

## Возможности

| Инструмент | Назначение |
| --- | --- |
| `get_status` | Готовность игры и NEI |
| `search_items` | Поиск предметов по названию, ID и моду |
| `get_item` | Данные предмета, NBT, подсказка и ордикты |
| `get_recipes` | Рецепты получения предмета |
| `get_usages` | Применения предмета в рецептах |
| `search_oredict` | Поиск групп ордиктов |
| `get_oredict` | Предметы указанной группы |
| `search_fluids` | Поиск зарегистрированных жидкостей |
| `list_adapters` | Доступные адаптеры и проверка форка |
| `list_recipe_maps` | Карты машинных рецептов выбранного адаптера |
| `search_machine_recipes` | Полные данные зарегистрированных машинных рецептов |
| `get_machine_recipe` | Подробности рецепта по ID из поиска |
| `get_recipe_authoring_guide` | Скилл и API для самостоятельного написания Kotlin-рецептов ИИ |
| `list_recipe_drafts` | Сохранённые пользователем черновики визуального редактора |
| `get_recipe_draft` | Данные черновика по его ID для написания кода ИИ |

Предмет задаётся через `item`, например `minecraft:iron_ingot`, и необязательные `metadata` и `nbt`.
Списки поддерживают `offset` и `limit` (по умолчанию 20, максимум 100).
Все инструменты работают на чтение. Ошибки обработчиков NEI возвращаются в `warnings` с `complete=false`.

## GT Impact и написание рецептов

Встроен адаптер `gregtech-impact` для [GT Impact](https://github.com/GT-IMPACT/GT5.09OFFBEAT).
Он проверяет признаки форка и совместимость API; другие GregTech форки автоматически не подключаются.
Доступность показывает `list_adapters`.

В запросах адаптера укажите `adapter: "gregtech-impact"`. Машинные рецепты содержат жидкости,
время, EU/t, вероятности, NBT и особые условия. Assembly Line возвращает исследования и альтернативы по слотам.
Поиск принимает `map`, `item`, `metadata`, `nbt`, `fluid`, `direction` (`input`, `output`, `any`) и `query`.
По умолчанию скрытые, fake и отключённые рецепты исключены; для них есть `includeHidden`, `includeFake`, `includeDisabled`.
Динамически вычисляемые рецепты не перечисляются, непрозрачные поля отмечаются в `warnings`.

Скилл автоматически распаковывается в `forgemcp/skills/gt-impact-recipes/`.
Для работы без отдельной установки скилла попросите ИИ:

> Прочитай get_recipe_authoring_guide для gregtech-impact. Используй данные MCP и напиши рецепт на Kotlin.

MCP предоставляет данные и руководство, а код пишет сам ИИ. Генерации и применения кода через MCP нет.
Архитектура подключения других форков описана в [docs/ADAPTERS.md](docs/ADAPTERS.md).

## Визуальный редактор

Адаптер `minecraft` читает общие реестры верстака и печки: shaped, shapeless,
Forge OreDictionary и плавку с опытом. Shaped сохраняет размеры, пустые клетки и зеркальность;
в редакторе выберите «Верстак — shaped» и заполните сетку. Для печки есть поле XP.
Нестандартные `IRecipe` и подклассы показываются отдельно как частичные данные:
их условия и динамический результат требуют чтения исходников.

Если установлен GT Impact, ИИ регистрирует также рецепты верстака/печки через
`GT_ModHandler`, согласно `craftingRegistration` в MCP. Адаптер чтения остаётся `minecraft`.
Другой форк GT требует своего проверенного профиля. Helper печки Impact задаёт XP=0:
ненулевой опыт нельзя потерять молча или обойти прямым вызовом Forge.
Скилл этих реестров распаковывается в `forgemcp/skills/minecraft-recipes/`.

1. Войдите в мир и выполните `/forgemcp ui`. Нажмите ссылку в чате.
2. Выберите адаптер и машину. Нажмите предмет в каталоге или перетащите его во входы/выходы.
3. Задайте количества, жидкости, вероятности, время, EU/t и особые условия. Кнопка «Данные» позволяет изменить metadata и NBT. «Вариант +» добавляет альтернативу входного слота.
4. Сохраните черновик и нажмите «Скопировать запрос для ИИ». ИИ прочитает его через MCP и сам напишет Kotlin-код.

Правая кнопка по предмету в каталоге открывает подробности и поиск рецептов получения.
Существующий машинный рецепт можно открыть как новый черновик. Для Assembly Line есть исследование с отдельным временем.
Ордикты можно добавлять во входы. Черновики сохраняются в `forgemcp/drafts/`, поддерживаются импорт/экспорт JSON.
В списке черновиков показаны миниатюры входов → выходов с количеством предметов и объёмом жидкостей.
Сохранение черновика не регистрирует рецепт в игре и не доказывает его совместимость с машиной.

«Выгрузить каталог и иконки» экспортирует весь список NEI в `forgemcp/export/catalog.ndjson`
(один JSON на строку) и прозрачные PNG 128×128 в `forgemcp/export/icons/`.
Иконки рендерятся сразу в этом разрешении; редактор плавно масштабирует их под размер ячейки.
Исходные текстуры Minecraft остаются пиксельными, но контуры объёмных предметов становятся детальнее.
Рендер идёт порциями на игровом потоке. Во время экспорта держите игру открытой; в фоне процесс может идти медленнее.
Нужны включённые framebuffer objects (FBO). Анимированные иконки сохраняются одним кадром.
Кэш разделён по составу модов и выбранным ресурспакам. После смены ресурспака перезапустите редактор через stop/ui.
Версия рендера также входит в кэш: после обновления мода исправленные иконки создаются заново.
Для обновления полной выгрузки `catalog.ndjson` повторите экспорт каталога и иконок.

Редактор упакован в мод, внешние Node.js/Python и CDN для работы не нужны.
Он слушает только `127.0.0.1`, по умолчанию на порту 25577, и запускается только по команде ui.
`/forgemcp stop` и выход из мира останавливают также редактор и текущий экспорт.
Экспортированный каталог и JSON остаются на диске; самостоятельный веб-сервер без игры в эту версию не входит.

### Схемы получения

Вкладка «Схемы» → «Выбрать предмет» показывает рецепты выбранного предмета из игры.
В редакторе также можно нажать ПКМ по предмету или жидкости → «Показать цепочку».
Предметы и жидкости соединены с карточками рецептов: входы → машина / рецепт → выходы.
Название и значок карты берутся из хандлера NEI: предмет, текстурный значок или первые две буквы названия.
Адаптеры GT Impact и Minecraft предоставляют подробные данные; другие хандлеры NEI показывают доступные слоты с отметкой о частичных данных.
По общим данным NEI нельзя надёжно определить жидкости, расход топлива, время, энергию или смысл дополнительных слотов.

Нажмите «Рецепты получения» на ингредиенте, чтобы раскрыть следующий уровень, или «Раскрыть цепочку» с глубиной 1–3.
Ордикты и альтернативные входы раскрываются выбором конкретного подходящего предмета.
Повторяющиеся предметы объединяются с учётом metadata и NBT, циклы отмечаются пунктирной связью.
Количество на связи относится к одному запуску рецепта, расчёт производительности цепочки не выполняется.
Первый поиск загружает до 100 рецептов из каждого источника; «Ещё рецепты» загружает следующую порцию.
На доске максимум 300 карточек. Это позволяет постепенно исследовать цепочку без полной выгрузки всех зависимостей.

Карточки перемещаются за заголовок; фон перемещает доску, колесо меняет масштаб, «Вместить» показывает всю схему.
Схема автоматически сохраняется в браузере; «Экспорт схемы» / «Импорт схемы» переносит её файлом JSON.
Сохранённая схема — снимок рецептов. После изменения сборки выберите предмет заново для получения актуальных данных.

## Сборка

```powershell
.\gradlew.bat build
```

Результат: `build/libs/forgeaimcp.jar`. Мост, инструкция и скилл уже внутри JAR.
Сборка также запускает тесты распаковки, подключения и жизненного цикла MCP.
