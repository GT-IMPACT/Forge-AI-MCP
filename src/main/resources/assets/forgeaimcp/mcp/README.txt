Подключение ForgeMCP

1. Войдите в мир и выполните /forgemcp start.
2. Откройте mcp.json в этой папке. Добавьте запись forgemcp в настройки
   MCP-клиента. Все пути и порт уже настроены для этой игры.
   Для клиента с настройками в TOML используйте блок из codex.toml.
3. Подключитесь к серверу forgemcp из MCP-клиента.

Python и отдельная установка Java не нужны: используется Java игры.
Папка с файлами доступна по команде /forgemcp config.
Остановка: /forgemcp stop. Состояние: /forgemcp status.
При выходе из мира MCP останавливается.

Автостарт по умолчанию выключен. Включается параметром autoStart=true
в config/forgeaimcp.cfg. Порт по умолчанию: 25576.
После изменения настроек перезапустите игру: файлы подключения обновятся.

Эта папка управляется модом. При обновлении мода её файлы обновляются
автоматически. Изменения настроек MCP-клиента вносите в сам клиент.
